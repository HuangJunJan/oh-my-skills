# 数据层

## 事务边界
事务内不要做外部 HTTP/RPC、发邮件、长耗时计算。
检验：事务内的操作能在 100ms 内完成吗？— 不能就拆出来。

## 并发写入
写操作优先用数据库唯一约束、幂等 key、`ON CONFLICT` 等保证并发正确性。

## 防 N+1
列表/批量查询显式审查 eager/lazy、JOIN、IN、dataloader 或批处理。

## Schema 变更
- schema 变更走迁移工具。
- 新增高频查询同步考虑索引，删除字段同步处理索引/约束。

## SQL 安全
SQL/命令/查询必须参数化或使用安全 builder，禁止字符串拼接不可信输入。
