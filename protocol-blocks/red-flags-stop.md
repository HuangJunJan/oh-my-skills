# Red Flags — STOP 块

以下任何一条出现，立即停下，不要自我协商：

## 通用 Red Flags

- [ ] 发现自己在说"应该没问题"/"看起来能跑"
- [ ] 发现自己在想"就这一次跳过 AAR"
- [ ] 任务声明"完成"但没跑 30 秒扫描
- [ ] 把 gotcha 写进了 reference，但没更新对应 workflow 的完成清单
- [ ] 修了同一类 bug 第二次，但规则文件没动过
- [ ] 发现自己在写"如果你还需要…" —— 已经说完了，收尾
- [ ] 发现自己在列 A/B/C 但不给推荐
- [ ] 发现自己在反问用户能用代码/文档查到的问题
- [ ] 工具不可用时手工模拟结果
- [ ] 用 bash 语法在 PowerShell 里硬跑（或反过来）

## 编辑 Red Flags

- [ ] "这个 catch 只是以防万一"
- [ ] "顺便格式化/重命名/升级依赖"
- [ ] "先加个 any 跑通再说"
- [ ] "鉴权后面再补"
- [ ] "先用 mock 数据，后面再换"
- [ ] "这个 useEffect 先放着，以后再优化"
- [ ] "事务里做个 HTTP 调用问题不大"
- [ ] 编辑会让 SKILL.md 超过 100 行
- [ ] 编辑没有对应的 AAR 扫描证据

## 审查 Red Flags

- [ ] 发现自己在写"建议优化一下代码质量"（无具体位置）
- [ ] 发现 level 标签全是 "Major"（无 Blocker 无 Minor）
- [ ] 审查结论没有明确说"可合并/需修/信息不足"
